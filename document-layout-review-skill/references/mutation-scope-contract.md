# 修改范围与内容保护

## 分块边界

一份原件、一份当前工作文档；以完整正文段落组、整表及题注、图片及题注作为修复单位。一两页仅为查看窗口，不拆 Word。块 ID 保持稳定，新增题注等导致节点数量变化时更新后续定位，不按旧页码猜位置。

`checkpoint` 在采纳拟稿前对比当前文档：块外节点、已有共享样式和编号定义、非目标媒体及关系、分节/页面设置必须不被局部修复改变。发现越界则拒绝拟稿，保留已完成的工作结果；随后在真正保存前检查块内业务内容、实际文字格式及域边界，任何失败都不推进。

## 目标对象内也要最小修改

| 修复目标 | 可以改变 | 不能顺手改变 |
|---|---|---|
| 正文/标题/题注文字样式 | 目标段落和 run 的模板属性、冲突覆盖 | 业务文字、图表几何、媒体、分节 |
| 空格/标点 | 确认错误的具体字符 | 数字、英文合法空格、URL、代码、公式及原有对象结构 |
| 表格样式 | 模板表内文字、边框、底色、对齐等 | 未确认的列宽、合并、内容 |
| 表格几何 | 目标表宽度、列宽、必要跨页属性 | 刚确认的文字/外观、独立记录内容；合并须另作语义判断 |
| 图片布局 | 目标图位置、等比大小与必要分页 | 原图像素、语义、配色、裁切内容 |
| 图内修复 | 有实际缺陷的目标图内容或明确授权重绘 | 非目标图，原有文字、节点、方向、连接、分支和正常风格 |
| 原生编号 | 当前标题/题注/脚注真实结构及已确认关系 | 表格内容、其他图片、分节和未授权正文 |

同一块可以按依赖先后处理以上动作，不要求每个动作重跑全文流水线。既有 `layout_invariant_guard.py` 可用于某一次精确操作；不能以块边界检查通过代替目标对象内的内容和样式验证。

## 共享设置与附属内容

共享样式、编号定义、页面和页眉页脚先全局准备一次。局部操作只允许新增不影响既有对象的独立定义，不改现有共享定义。后续确有共享缺陷时单独提交 `shared`，不伪装成局部操作；最终验收据实际影响范围失效，块进度不全部清零。

页眉页脚、脚注、尾注有明确部件检查项，其内部图表同样进入对象清单。已有附属部件增删段落时同步更新范围；先验证新文档与新范围一致，再原子提交，不能保存后才发现范围失效。正文块内允许处理其专属脚注关系及内容迁移，但不能改其他块的注释；原文定位必须经内容保护程序核验。共享媒体不能在一个块里直接替换而影响其他位置，应创建仅被目标对象引用的新媒体及关系。

## 内容与恢复

最终内容完整性检查直接对照最初原文，不以最新候选重置基准。仅允许本次规则规定的格式性变更、规范空格/标点、真实编号变化、已登记新题注和准确脚注迁移。表格合并后按逻辑单元格核对内容。

工作文件、模板、规则或进度被外部改动时先查明原因；不能手工修改哈希或清空问题台账。失败拟稿不作为下一轮输入。断点恢复保留已完成的正确块，从待修块或失败验收步骤继续。
