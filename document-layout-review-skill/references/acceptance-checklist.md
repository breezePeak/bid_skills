# 最终验收清单

与 `SKILL.md` 第 5—8 节共同执行。**每次最终修改后重新核验，任一未通过就按第 7 节返回对应修复步骤，不交付。**

检查对象是当前最终候选及最新页图。程序检查、实际看图、语义判断和内容保护均须通过，不能相互替代。使用现有审计、页面、图片及表格 review 记录，不要求用户另填表。

## 1. 基准和证据

- [ ] 原始 Word 保留不变；内容计划仍指向原文，不以候选充当原文。
- [ ] 本轮使用原定模板、样式约定、文字规则、图片初检及有效对象计划；必要变更经过确认并重新生成对应证据。
- [ ] 当前文件对应全部必需审计；无漏项、旧版本清单、过期报告或手工补写的通过结论。
- [ ] 实际更新域的输出、审计的候选、渲染的文件和交付候选是同一版；最后修改后未复用旧结果。
- [ ] 页面清单与实际输出完整对应；正文、表格、图片、原生 Shape、脚注及页眉页脚没有因脚本未覆盖而漏检。

失败：恢复正确基准、执行遗漏检查或重新生成当前证据；不能改哈希或状态来“匹配”。

## 2. 模板和文字样式

- [ ] 样式定义、继承、实际角色及实际生效格式符合模板；没有未解决的映射或继承冲突。
- [ ] 可见 run 的字体、字号、字重、斜体均按本次规则逐一核对，单个错误 run 也未被覆盖率放行。
- [ ] 颜色、下划线、高亮、底纹、边框及段落格式没有与模板冲突的直接或继承残留；模板的“无”也得到应用。
- [ ] 正文黑体默认保留与用户明确覆盖按既有文字规则处理；保留黑体不等于保留错误加粗；公式上下标等语义属性未误删。
- [ ] 标题、正文、表格文字、题注、脚注和页眉页脚分别使用其正确格式，没有统一成一个正文样式。

失败：定位实际覆盖来源，修复同类异常文字/段落；不得连带改动表格几何和图片。

## 3. 标题、题注、脚注和引用

- [ ] 标题层级真实，原生多级编号与标题样式绑定；字形、前后缀、分隔符及续号与模板相符；无双重手工前缀。
- [ ] 业务图表的缺注已补；独立 Word 题注固定**图下表上**，图与图题同页，表题与表格起始部分同页。
- [ ] 图与表各自按一级章节从 1 自动递增，显示“图1 题名”“表1 题名”；无章节前缀、漏号、重复号和图内烧录的外部题注。
- [ ] 图表使用完整、未锁定的独立 SEQ 域；无标题文字、样式显示名、书签参数或 STYLEREF 章节拼接依赖；重启不绑首张图表。
- [ ] 最后修改后已经真实更新并保存，序号重新计算正确，无“未定义样式”“未找到引用源”“未定义书签”等错误。
- [ ] 本次修过编号结构或更新组件恢复过域指令时，已用刷新输出再刷新一次并复核；最终审计和渲染使用最后一次输出及其报告。
- [ ] 任务中的标题文字/样式名/编号显示格式修改没有破坏图表更新；修改编号代码时的增删首图表、改名和重复刷新回归遵循 `caption-baseline.md`，不能拿单次缓存正确代替。
- [ ] 脚注是原生引用和自动序号，内容对应完整，无孤立/重复脚注；正文上标、参考文献、公式指数没有误转。
- [ ] 正文上下图/表引用已核对目标及方向，无定位歧义；装饰图或布局表豁免有实际用途依据。

失败：恢复位置、真实层级/列表、SEQ 和引用关系后重新实际更新。不得锁域、手填数字、过滤题注位置错误或篡改缓存。

## 4. 表格

- [ ] 已读表头、各列用途和实际内容，且已运行表格宽度、模板外观及模板布局审计。
- [ ] 所有表格在当前节可打印范围内，不靠改横向、扩大纸张或整体缩小字体逃避越界。
- [ ] 短列紧凑、长列有空间，无明显一字一行、异常碎裂表头和无内容依据的突兀宽窄差；整表在最新页面上协调。
- [ ] 长 URL、路径、标识符等不会撑宽整表/页面；调整断行方式没有改写字符串本身。
- [ ] 底色（含无底色）、边框、文字颜色和条件样式符合模板；宽度修复没有改回旧格式。
- [ ] 对齐、内边距、表头重复及行规则符合生效模板；默认技术标表内首行缩进为 0，不继承正文缩进。
- [ ] 每个 `review` 已查实际语义：应合并的同组重复单元格已合并，不应合并的独立记录保持独立并写明原因。
- [ ] 合并后逻辑单元格内容、列跨度、行列对应无损；不同内容未被隐藏或丢失。
- [ ] 起始页、续页、结束页的表头、边框、行内容和上下文均可读，无异常大空白、裁切或跨页歧义。

失败：按具体原因分别修列宽、模板外观或语义合并。数值合法而视觉失衡仍须修；需要修改的 review 不能只填“可接受”。

## 5. 图片和流程图

- [ ] 实际图片、架构图、技术路线图、流程图和原生 Shape 清单完整，原图与最终对象对应正确。
- [ ] 已看完整原图并放大检查文字边界、窄框、节点、连线及标签；不把 Word 外部图题误判为内嵌题注。
- [ ] 最终图清晰、比例正确，不越界、不裁切、不变形；按页面实际显示大小仍能读清文字。
- [ ] 文字不出框、节点不重叠、连线不穿无关节点；节点/方向/分支/标签/分组与原意一致，没有为塞进框而删内容。
- [ ] 图内缺陷得到实际修复；初检失败项逐项在新图复核，未以改 JSON、填 PASS 或整体缩图代替修复。
- [ ] 正常原图只改大小/位置/分页时，原媒体与内部内容保持不变；独占页的图和图题同页且前后正文完整。
- [ ] 确需重绘时，原图与新图已并排核对，原有正常风格没有被脚本默认主题覆盖。
- [ ] 每张图终检同时核对最终图和所在最新页，页图/对象证据属于当前候选；不能只看脱离文档的新图。

失败：图内问题修图；页面空间问题先调布局，必要时独占页。无法辨认原文字或连接时取得清晰源资料，不猜画。

## 6. 页面和分节

- [ ] 页面尺寸、方向、页边距、分节、页眉页脚和页码符合模板；非目标节没有被误改。
- [ ] 没有异常空白页、孤立标题、字体错位、图文/页眉页脚重叠或内容跑出页面。
- [ ] 分页调整不靠堆空段，未截断表格行、遗漏前后正文或使图题脱离对象。
- [ ] 受影响页及相邻页已定点复查；最终全部最新页面已经逐页看过，不只是抽查或查看缩略拼图。

失败：修对应节、段落分页或对象位置，再检查页码、目录和前后页，不用改纸张掩盖。

## 7. 空格和标点

- [ ] 中文和英文/代码/公式语境中的标点各自正确，中文引号为 `“……”`，没有已确认的重复或错误标点。
- [ ] 中文之间、标点周边、括号/引号、段首段尾、单元格首尾的无意义空格已清理。
- [ ] 跨 run、全角空格、NBSP、零宽脏字符及日期/时间/数量单位已检查；如“2026 年 10 月 31 日”“软件 1 套”的无用空格已修正。
- [ ] 合法英文、URL、路径、代码、公式、中英混排空格及数字负号/小数点未误删或替换。

失败：按整段语境定位具体字符，只改字符，保持原有允许格式和对象结构。

## 8. 内容保护与最终结论

- [ ] 内容审计直接对照原始 Word；业务文字、数字、表格逻辑内容、脚注及引用无未允许的增删改、遗漏或重复。
- [ ] 新题注、编号、脚注搬移和语义确认后的合并能对应有效计划及真实源内容；未用宽泛白名单放行未知变化。
- [ ] 各轮修改范围比较未留下非目标对象损坏；发现的误伤已恢复并重新修复验证。
- [ ] 所有程序错误已解决；所有 review 已实际修改或有具体保留理由；所有视觉缺陷已关闭；没有必需但未执行的验证。
- [ ] 最终交付入口成功输出当前 Word；入口失败没有被候选改名或手工 PASS 绕过。
- [ ] 交付修复 Word 和实际修复报告，报告只写生效修改与真实验证范围；没有冒称 Windows Word F9 实测。

**任一项仍失败、漏检、待确认或未验证：停止交付，记录位置和原因，按 `SKILL.md` 第 7 节修复、更新域、重新审计、渲染、再验收。只有确实不适用的检查才能说明理由后排除，不给已有缺陷做豁免。**
