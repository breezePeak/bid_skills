# 最终验收清单

每次最终修改后都从头执行。

## 内容
- [ ] 文字、数字、表格内容未丢失
- [ ] 无重复段落
- [ ] 无因排版修复产生的内容改写

## 模板/样式
- [ ] 全部格式以生效模板及用户特殊要求为准，没有以“原文如此/保持原样”保留与模板冲突的格式
- [ ] 初检、模板应用、修复和复查使用同一份本次文字规则
- [ ] 正文字体/字号/加粗/斜体符合本次规则；行距/缩进等其他项目仍符合基准
- [ ] 正文已按可见 run 逐一核验字体/字号；不存在违反本次规则的局部字体/字号
- [ ] 各级标题实际样式符合基准
- [ ] 表格和题注实际使用正确样式
- [ ] 无违反本次规则的字体/字号/加粗/斜体；未用默认保留项覆盖用户明确禁止的要求
- [ ] 页面、页眉页脚符合模板

## 自动编号
- [ ] 初检、修复、复查使用同一实际模板；不是沿用坏文档的章节写法
- [ ] 一级/多级编号的字形、前后缀、分隔符及后缀与模板一致；标题样式也绑定列表
- [ ] 图表分别每章从1开始，不显示“图2.1/表3.2”，题注没有 STYLEREF 章节拼接
- [ ] 每个业务图表都有独立题注，图下表上；豁免对象确为装饰图或布局表
- [ ] 正文引用已定位并改为上下图/表，方向正确，没有用模糊描述掩盖歧义
- [ ] 已运行 `numbering_audit.py`，没有未解决的 error/review
- [ ] 标题使用有效多级编号，编号层级与标题层级一致，无重复手工前缀
- [ ] 题注使用独立 SEQ 图/表域；章节边界重启，不逐条固定重启，不把编号烧进图片
- [ ] 脚注为原生引用及自动序号，引用与内容对应，无孤立或重复脚注
- [ ] 更新域并查看最新页面，编号、交叉引用、脚注顺序和分页正常

## 表格
- [ ] 已运行 `table_layout_audit.py`
- [ ] 先通过模板符合性检查，再对列宽修复执行 `table-layout` 比较；未把错误原文外观作为冻结标准
- [ ] 已运行 `template_table_style.py audit`；表头/行底色、边框、文字颜色和 Table Style 符合生效模板，模板无底色时不存在原灰底/蓝底残留
- [ ] 不越出当前节可打印宽度
- [ ] 每列宽度同时考虑表头字数、列用途和正文内容量
- [ ] 无明显“一列特别窄、另一列无必要特别宽”的突兀比例
- [ ] 相邻列的明显宽度差能够由内容压力或特殊语义解释
- [ ] 无明显一字一行或表头被异常拆碎
- [ ] 长文本列没有被挤在过窄列中
- [ ] 无长 URL/路径/标识符导致 autofit 异常拉宽页面的风险
- [ ] `review` 级纵向合并候选已逐项处理
- [ ] 同一语义分组中应合并的连续重复单元格已经纵向合并
- [ ] 独立记录没有因为文字相同而被误合并
- [ ] 合并后其他列与原始行对应关系不变，没有丢内容
- [ ] 单元格上下居中
- [ ] 表格内文字首行缩进为 0
- [ ] 表头和跨页可读
- [ ] 无异常大空白
- [ ] 最新渲染页面中整表视觉比例协调，短列不空旷、长列不拥挤

## 图片/流程图
- [ ] 对象清单与原图、最终图逐一对应；架构图、原生Shape和无箭头图没有漏检
- [ ] 查看的是实际图像，不将 Word 外部图题误认为内嵌图题
- [ ] 图像内容中无外部图号/题注；文字边界、侧边窄框均检查
- [ ] 初检出框/重叠/内嵌题注等缺陷逐项关闭，不能以修改报告代替修改图
- [ ] 图的终检关联最新页面；未改动的原媒体不能证明图内硬缺陷已修复
- [ ] 图片清晰、不变形、不裁切
- [ ] 已区分图内缺陷和页面空间不足；未因图片较大就重绘
- [ ] 仅调大小/位置/分页时已通过对应 scope 比较，原媒体和图内风格未改变
- [ ] 确需重绘时已并排比对原图与新图，原有良好风格未被默认主题覆盖
- [ ] 流程图节点完整
- [ ] 箭头 from/to 正确
- [ ] 分支/回路正确
- [ ] 连线不穿无关节点
- [ ] 标签不歧义
- [ ] 文字不出框

## 页面
- [ ] 页面尺寸、方向、页边距正确
- [ ] 分节正常
- [ ] 无异常空白页
- [ ] 无内容跑出页面
- [ ] 独占页的图与图题同页，未改页面方向、拉伸图片或遗漏前后正文

## 文字
- [ ] 中文语境使用中文标点
- [ ] 英文/代码/公式使用半角标点
- [ ] 中文引号为 “……”
- [ ] 无明显重复标点
- [ ] 无确认出的无意义空格
- [ ] 已检查中文标点前后、括号/引号周边、跨 run 边界、全角空格、NBSP、零宽空格

## 视觉
- [ ] 最后修改后由真实 Office 引擎更新域/目录，记录绑定当前文件哈希
- [ ] 刷新后没有样式错误、旧缓存、SEQ 章节重启开关丢失等问题
- [ ] finalize_review.py 的全部必需检查齐全，逐页和逐图记录完整
- [ ] 已渲染最新 DOCX
- [ ] 最终交付已逐页检查全部页面；修复迭代也已核对受影响页面及相邻页
- [ ] 表格列宽在真实页面中协调，没有程序数值合法但肉眼明显失衡的情况
- [ ] 无肉眼可见的裁切、重叠、错位、字体异常或难以阅读的版面

任一项未通过：返回对应修复步骤，不交付。
