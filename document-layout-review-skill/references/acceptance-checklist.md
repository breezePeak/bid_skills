# 最终验收清单

每次最终修改后都从头执行。

## 内容
- [ ] 文字、数字、表格内容未丢失
- [ ] 无重复段落
- [ ] 无因排版修复产生的内容改写

## 模板/样式
- [ ] 正文实际字体/字号/行距/缩进符合基准
- [ ] 正文已按可见 run 逐一核验字体/字号；不存在一个词、一句话或局部 run 夹杂错误字体/字号
- [ ] 各级标题实际样式符合基准
- [ ] 表格和题注实际使用正确样式
- [ ] 无与基准冲突的 run 级字体/字号 direct formatting；无大面积加粗/斜体等 direct formatting 污染
- [ ] 页面、页眉页脚符合模板

## 表格
- [ ] 不越界
- [ ] 无明显一字一行
- [ ] 长短列宽度合理
- [ ] 单元格上下居中
- [ ] 表格内文字首行缩进为 0
- [ ] 表头和跨页可读
- [ ] 无异常大空白

## 图片/流程图
- [ ] 图片清晰、不变形、不裁切
- [ ] 流程图节点完整
- [ ] 箭头 from/to 正确
- [ ] 分支/回路正确
- [ ] 连线不穿无关节点
- [ ] 标签不歧义
- [ ] 文字不出框

## 页面
- [ ] 页面尺寸、方向、页边距正确
- [ ] 分节正常
- [ ] 无异常空白页
- [ ] 无内容跑出页面

## 文字
- [ ] 中文语境使用中文标点
- [ ] 英文/代码/公式使用半角标点
- [ ] 中文引号为 “……”
- [ ] 无明显重复标点
- [ ] 无确认出的无意义空格
- [ ] 已检查中文标点前后、括号/引号周边、跨 run 边界、全角空格、NBSP、零宽空格

## 视觉
- [ ] 已渲染最新 DOCX
- [ ] 已检查全部页面或所有受影响页面及相邻页
- [ ] 无肉眼可见的裁切、重叠、错位、字体异常或难以阅读的版面

任一项未通过：返回对应修复步骤，不交付。
