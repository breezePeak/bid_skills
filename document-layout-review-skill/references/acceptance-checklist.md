# 最终验收清单

每次最终修改后都从头执行。

## 内容
- [ ] 文字、数字、表格内容未丢失
- [ ] 无重复段落
- [ ] 无因排版修复产生的内容改写

## 模板/样式
- [ ] 正文实际字体/字号/行距/缩进符合基准
- [ ] 正文已按可见 run 逐一核验字体/字号；不存在一个词、一句话或局部 run 夹杂错误字体/字号
- [ ] 各级标题实际样式符合基准
- [ ] 表格和题注实际使用正确样式
- [ ] 无与基准冲突的 run 级字体/字号 direct formatting；普通正文无错误直接加粗/斜体
- [ ] 页面、页眉页脚符合模板

## 表格
- [ ] 已运行 `table_layout_audit.py`
- [ ] 不越出当前节可打印宽度
- [ ] 每列宽度同时考虑表头字数、列用途和正文内容量
- [ ] 无明显“一列特别窄、另一列无必要特别宽”的突兀比例
- [ ] 相邻列的明显宽度差能够由内容压力或特殊语义解释
- [ ] 无明显一字一行或表头被异常拆碎
- [ ] 长文本列没有被挤在过窄列中
- [ ] 无长 URL/路径/标识符导致 autofit 异常拉宽页面的风险
- [ ] `review` 级纵向合并候选已逐项处理
- [ ] 同一语义分组中应合并的连续重复单元格已经纵向合并
- [ ] 独立记录没有因为文字相同而被误合并
- [ ] 合并后其他列与原始行对应关系不变，没有丢内容
- [ ] 单元格上下居中
- [ ] 表格内文字首行缩进为 0
- [ ] 表头和跨页可读
- [ ] 无异常大空白
- [ ] 最新渲染页面中整表视觉比例协调，短列不空旷、长列不拥挤

## 图片/流程图
- [ ] 图片清晰、不变形、不裁切
- [ ] 流程图节点完整
- [ ] 箭头 from/to 正确
- [ ] 分支/回路正确
- [ ] 连线不穿无关节点
- [ ] 标签不歧义
- [ ] 文字不出框

## 页面
- [ ] 页面尺寸、方向、页边距正确
- [ ] 分节正常
- [ ] 无异常空白页
- [ ] 无内容跑出页面

## 文字
- [ ] 中文语境使用中文标点
- [ ] 英文/代码/公式使用半角标点
- [ ] 中文引号为 “……”
- [ ] 无明显重复标点
- [ ] 无确认出的无意义空格
- [ ] 已检查中文标点前后、括号/引号周边、跨 run 边界、全角空格、NBSP、零宽空格

## 视觉
- [ ] 已渲染最新 DOCX
- [ ] 已检查全部页面或所有受影响页面及相邻页
- [ ] 表格列宽在真实页面中协调，没有程序数值合法但肉眼明显失衡的情况
- [ ] 无肉眼可见的裁切、重叠、错位、字体异常或难以阅读的版面

任一项未通过：返回对应修复步骤，不交付。
