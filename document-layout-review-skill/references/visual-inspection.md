# 按块看图与最终页面核验

## 必须检查的内容

处理到含图块时看完整原图、重叠局部及四周边界，逐个文字块对照所属框。侧栏、竖框、外围说明不能漏掉。没有箭头不能豁免文字边界；原生 Shape 不能因为没有媒体文件而漏检。

文字出框、重叠、裁切、不可读、连接/分组错误和图内烧录外部题注必须定位并修复。Word 中独立图题不属于图内烧录内容。修改后先看实际新图，语义、配色及正常风格对照原图；最终还要核对所在页面、尺寸、分页和图题关系。

## 执行方式

继续使用已授权的宿主视觉适配器。`visual_evidence.py` 将真实图片字节送入适配器，不以路径、OCR 文本或假回执代替图片。`--vision-worker-config worker.json` 指定命令配置；可选 HTTP 适配器的环境变量仍为 `DLR_VISION_API_URL`、`DLR_VISION_MODEL`、`DLR_VISION_API_KEY`。没有默认外部服务，不自动发送投标资料给新供应商。

初检按当前块触发，一次真实调用覆盖当前图的必要视图。正常图不预先等待全文图片检查。终检协议为 `dlr-visual-v2`，需要重新看图时执行一次当前对象检查；有不确定或未修复问题就失败，不按固定调用次数判合格。

## 允许复用什么

**图内未变，位置可能变：** 原图具有真实初检通过证据、当前媒体像素一致、没有已登记缺陷，并且所在的当前页面已有实际观察结果时，复用图内证据。记录明确标成 `unchanged-content-current-pages`，不是伪造一次新的终检调用。当前页面没有通过，图内通过不能替代页面验收。

**图和所在页均未变：** 当前对象、原图、规则及页面哈希全部匹配时，已有真正通过的最终图片检查可复用，原始请求/响应不改写。

**不能复用：** 图片修改、原生 Shape 渲染裁片变化、页面效果变化且缺少当前观察、初检失败或不确定、后续缺陷未闭合、规则改变、回执过期。同一原文的原生对象共用已验证的源渲染，不为每个 Shape 重新导出整本。原生 Shape 和无法解码的媒体，仍通过 `figure_review.py bind-rendered` 绑定真实文件渲染报告及完整对象裁片。

## 缺陷不能因续跑而消失

初检问题与后续新发现都对照原文保存。新增缺陷台账固定在会话的 `work/reports/image-discoveries.json`，所有终检轮次引用同一台账，不创建新空台账替代旧失败。

已登记图内缺陷而真实图像未变时，不能靠后来的 PASS 清除；只重新编码图片也不算修复。图片初检和每张已完成的终检结果及时保存，中断后不无故重新调用已完成对象。

## 页面与表格

按一两页窗口看实际最终页面，不能只看缩略拼图。每一页保留实际观察；每张实际表格都记录当前对象和所在页面、列宽/跨页/语义结果，而非只处理表格审计候选。脚本校验覆盖和结果绑定，不宣称能独立证明模型看清了图。

手工修改 `overall_status`、图片检查项或文件哈希不能使缺失/失败证据变成有效结果。没有可执行视觉接口时可以继续定位问题，但不能伪造正式检查回执。适配器接入、真实模型识别能力和 Word/WPS 兼容性必须在实际宿主验证；单元测试不代替这些验证。
