# 分块修复步骤

按 `SKILL.md` 的八类对象标准检查当前完整块，不按类别反复扫修全文。

| 当前问题 | 动作 | 本块复核 |
|---|---|---|
| 样式、字体或段落不符 | 按已锁定模板修对应属性，清除冲突的直接格式；保留明确例外 | 核对实际生效格式，正文/表格/图片非目标属性不变 |
| 表格列宽或跨页异常 | 理解整表后调整列宽、行约束和必要断行，不改纸张容纳 | 看整表和受影响页面，不以数值未越界代替可读性 |
| 同一对象重复分组 | 语义确认后合并，独立记录不合并 | 逻辑单元格内容、行列关系不丢失 |
| 图片或流程图内在缺陷 | 看原图并局部修复，保留内容、方向、标签和正常风格 | 先看实际新图；不以缩小整图或重编码解决出框 |
| 正常图片放不下 | 等比调整或图与图题独占页，不重绘正常图 | 核对前后衔接，最终页面确认可读性 |
| 标题、题注或脚注编号 | 修当前实际结构和域，不重建已正确的编号 | 本块核对域结构；全文结束统一真实刷新 |
| 空格或标点 | 跨 run 定位字符，保护代码、URL、路径、公式和业务数字 | 修对应字符，不重建整段 |
| 误改块外对象 | 拒绝拟稿，从当前工作文档重修目标 | 不恢复整份旧文档丢掉其他块正确结果 |

块内复核完成即保存并继续。等待最终分页确认的项目保留为待查，不无故重复当前块。最终发现问题只 reopen 所属块；同一措施无效先定位原因，不原样重跑整条链。

共同样式和页面设置在开头确定。后续确需修正共享定义时说明影响范围，使用独立共享修复入口，保留内容块进度但重验受影响的最终页面。
