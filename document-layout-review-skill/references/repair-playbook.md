# 修复策略

## 基本原则

- 只修问题对象及其必要属性，不重新设计正常图片，不给表头新增底色；
- 不改变事实、数字和业务含义；
- 确定性问题优先使用确定性方法；
- 视觉问题必须看最终页面；
- 任何修复后重新验收。

## 正文/标题

优先恢复正确的模板 style，再清除覆盖样式的错误 direct formatting。不要重新创建整段文字。正文允许保留的字体和强调格式由本次文字规则决定，应用模板或清除其他属性时不得连带破坏。初检、修复和复查统一传入 `--text-rules`；未提及的检查项不变。

## 自动编号和补题注

读取实际模板 styles/numbering 及其绑定，按模板恢复标题数字、层级、符号及间隔；已经自动编号但形式错误的标题也要纠正。不能从待修文档的“第一章/第1章”反推模板。正文业务文字、封面及目录不批量当标题重写。

图表按独立对象补题注，图下表上；各章图、表分别从1递增，不显示章节号，删除旧 STYLEREF 拼接。缺题名由 Agent 看内容后填写语义计划，程序插入真实 SEQ 域。正文引用先定位后改“见上/下图、表”。脚注继续使用原有原生转换逻辑。

同一模板传入修复、最终编号复核；实际更新域后再次检查和渲染。检查脚本只写缓存和 updateFields 标记不算 F9 完成。接口见 `numbering-rules.md`、`caption-and-image-review.md`。

## 表格

表格不能采用“看见窄列就随便拉宽”的方式修。先分析，再整体分配。

先由原有文字步骤按模板修字体、字号、零首行缩进等，再用 `template_table_style.py repair` 按模板统一底色、边框和颜色，通过其 `audit` 后再单独修列宽。模板无底色就清除原底色，模板有底色就应用；原格式不是保护基准。`table_layout_repair.py` 保护此时已经合格的模板外观。合并和物理网格变更仍单独确认、执行并核对。

布局修复前后执行 `layout_invariant_guard.py` 的 `table-layout` 比较。底色还须检查表格样式继承和 firstRow 等条件格式，不能只搜索直接 `w:shd`。

1. 识别表头和每列用途，标记 compact / medium / narrative 等语义角色；
2. 获取当前节可打印宽度，作为整表硬上限；
3. 统计每列表头长度、正文平均内容量、较长内容和最长内容；
4. 给短列设置能够正常阅读表头和正文的最小宽度；
5. 将剩余宽度按内容压力分给中等列和长文本列；
6. 检查相邻列是否存在无依据的极端宽窄反差；
7. 检查长 URL、路径、版本号、哈希、英文标识等不可断行内容，禁止让 autofit 把表格或页面拉宽；
8. 检查连续重复分组列：
   - 若“标的名称/项目名称/工作对象/类别/阶段/模块/工作包”等连续多行属于同一语义对象，则纵向合并；
   - 若各行是独立记录、独立状态或独立响应，则保持分开；
   - 无法判断是否会改变业务含义时，交给用户确认；
9. 合并后保持其他列与原行一一对应，不得丢内容或错位；
10. 同步写入稳定的 `tblGrid`、`tcW`、表格总宽度、单元格内边距、水平/垂直对齐和重复表头；
11. 重新运行 `table_layout_audit.py`；
12. 渲染真实页面，检查列宽是否协调、合并是否自然、跨页是否正常。

模板中的同表头列宽比例只能作为参考。如果当前正文内容明显不同，必须按当前内容重新平衡。

禁止靠以下方式掩盖问题：

- 整体缩小字号；
- 擅自改横向页面；
- 保留明显失衡的旧模板列宽；
- 因为两个单元格文字相同就机械合并；
- 只修改 `tblGrid` 却不更新实际单元格宽度。

## 流程图

先看全图，区分图内缺陷与页面空间不足。原图正常时保留媒体和风格，合理调整大小/位置；当前页放不下则让图与图题独占一页，允许增加页数，不改横向，不拉伸。

只有图内确有问题且无法靠文档布局解决，或者用户明确要求重新设计，才重绘。无法理解全图时不要猜画。

确需重绘才重建：
- 节点；
- 节点类型；
- 文本；
- from/to；
- 分支标签；
- 汇合；
- 回路；
- 主方向。

校验语义后用可靠图布局引擎进行必要调整，保留原配色、方框/圆角、字体风格与分组；不得使用脚本默认主题覆盖原图。替换前并排检查原图和新图。必须避免：
- 线穿节点；
- 箭头指错；
- 歧义交叉；
- 分支标签错线；
- 文字出框；
- 图过小。

## 页面

图本身正常但当前页拥挤时，分页优先于重绘。使用现有图片段、题注段及后续正文段的分页属性，让图与图题同页；用 `figure-pagination` 比较，保证媒体、图形、文字样式和分节不变。先后分别完成分页、图片大小调整，再重新渲染所有受影响页及相邻页。除非模板或用户要求，不要切换横向。

## 标点/空格

按段落语境判断，尽量原位替换字符，保持原 run 格式。不能确认时不自动改。
